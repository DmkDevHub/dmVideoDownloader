# UI_SPEC — Windows 프로그램 및 확장 팝업 화면

## 1. 구성 제한

- Windows 프로그램: **메인 화면 1개 + 설정 창 1개**. 초기 버전은 한국어 UI.
- 확장 프로그램: 현재 탭 영상 후보를 보여주는 작은 팝업 1개. 브라우저 옵션 페이지나 별도 사용자 계정 페이지는 만들지 않음.
- 관리자용 대시보드, 사용자 프로필, 로그인/회원가입, 통계/광고 UI를 만들지 않음.

## 2. 메인 화면 와이어프레임

```text
┌──────────────────────────────────────────────────────────────┐
│ Video Downloader                                [설정 ⚙]     │
├──────────────────────────────────────────────────────────────┤
│ [영상 URL 직접 입력 _________________________] [분석]        │
│ Chrome 연동: [연결됨/미등록/실패]  자동 감지: [켜짐/꺼짐]     │
├──────────────────────────────────────────────────────────────┤
│ 감지된 영상                                                   │
│ [제목] [사이트] [종류] [분석 상태]            [다운로드]       │
│ [제목] [사이트] [종류] [분석 상태]            [다운로드]       │
├──────────────────────────────────────────────────────────────┤
│ 다운로드                                                      │
│ [제목] [화질] [진행률/속도] [상태] [일시정지/취소]             │
├──────────────────────────────────────────────────────────────┤
│ [다운로드 폴더 열기]                       [진단 메시지]      │
└──────────────────────────────────────────────────────────────┘
```

## 3. UI 상태 표시

| 상태 | 화면 문구 예시 | 규칙 |
|---|---|---|
| 발견/미분석 | `영상 감지됨 · 화질 확인 필요` | 화질/용량 지어내지 않음 |
| 분석 중 | `영상 정보를 분석하고 있습니다` | 진행 상태 제공 |
| 다운로드 가능 | `1080p · 다운로드 가능` | 분석 완료 때만 표시 |
| 다운로드 중 | `68% · 5.2MB/s` | 실제 프로세스 출력 기반 |
| 병합 중 | `영상과 음성을 결합하고 있습니다` | 다운로드 완료와 구분 |
| 인증 필요 | `인증이 필요한 영상입니다` | 브라우저 세션 사용 버튼 없음 |
| DRM 또는 보호 의심 | `보호된 영상이거나 분석할 수 없습니다` | 확정적 판정이 불가능하면 표현 완화 |
| 주소 만료 | `영상 주소가 만료되었거나 접근할 수 없습니다` | 재감지 안내 가능, 토큰 재사용 안 함 |
| 연결 실패 | `브라우저 연결이 설정되지 않았습니다` | 설정 창의 연결 관리 안내 |

## 4. 설정 창

상세 옵션과 JSON 스키마는 `SETTINGS.md`를 단일 기준으로 사용한다. 메인 화면 [설정] 버튼 하나로만 연다. 설정 저장 실패 시 창을 닫아 성공한 척하지 않는다. [취소]는 저장하지 않고 닫는다.

## 5. 확장 팝업

```text
[현재 탭에서 감지한 영상: N개]
[영상 제목] [MP4/HLS/DASH] [화질 미확인] [다운로드]
[영상 제목] [MP4/HLS/DASH] [화질 미확인] [다운로드]
[연결 상태 / 실패 이유]
```

- 감지 자동 실행 자체는 다운로드를 시작하지 않는다.
- 동일 페이지의 세그먼트 하나하나가 별도 영상 행이 되지 않도록 한다.
- 연결 문제를 사용자가 이해할 수 있는 문구로 안내한다.

## 6. 접근성/사용성

- Windows 폴더 선택창 사용, 키보드 이동과 명확한 포커스 상태 지원.
- 재시도/취소 버튼은 동작 가능한 상태에서만 노출하거나 활성화.
- 긴 영상 제목/경로는 말줄임 처리하고 전체 값은 상세 정보로 확인 가능하되, **원시 URL 쿼리/비밀 값은 표시하지 않음**.
- 진행률이 추정 불가능할 때는 `진행 중`으로 표시하고 가짜 퍼센트를 보여주지 않는다.

## 7. 검증

실제 Windows UI에서 [설정] 열기/저장/취소, 폴더 선택, 브라우저 연결 상태 갱신, 감지→다운로드 작업 추가, 오류 문구, 작업 일시정지/취소 버튼을 테스트한다. `docs/TEST_PLAN.md`의 TC-01~20과 연결한다.

## 8. Chrome 설치·연결 UI (v1.2)

설정 창 하단에 `Chrome 확장 프로그램` 영역을 둔다. [확장 프로그램 설치 안내]는 동일 창 안의 단계 안내를 펼치며 별도 설정 창을 만들지 않는다. 버튼/즉시 적용 규칙/필드의 기준은 `SETTINGS.md` 7절이다.

```text
Chrome 확장 프로그램
확장 연결: 확인 필요             Native Messaging: 미등록
[확장 프로그램 설치 안내] [확장 폴더 열기]
[Chrome 확장 관리 주소 복사]
개발자 모드 → unpacked 로드 → ID 복사 → 등록 → 테스트
확장 ID: [________________________________]
[호스트 등록] [연결 테스트] [연결 복구/재등록] [연결 해제]
```

테스트 대기 중에는 `30초 안에 확장 팝업의 [연결 테스트]를 누르세요`를 표시하고 중복 클릭을 막는다. 팝업은 실제 ID·[ID 복사]·[연결 테스트]·진단 결과를 제공한다. 설치 전에는 `설치 확인 필요`, 등록 후에는 `등록됨 · 테스트 필요`, 실제 왕복 확인 후에만 `연결됨`을 사용한다. 실패 시 폴더/ID/등록/Chrome 활성화 확인 순서를 제시한다. 폴더 이동 시 `새 경로로 재등록 필요`, ID 변경 시 `ID 변경 · 재등록 필요`를 표시한다. 마지막 성공 시각을 현재 연결 상태와 분리한다. 웹스토어 강제 설치나 개발자 모드 자동 변경 기능은 없다.

설치·연결 검증 범위는 TC-16~20까지 포함한다.
