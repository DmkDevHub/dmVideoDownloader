## 1. 설치와 첫 실행

1. **`VideoDownloaderPortable-win-x64.zip`**을 준비합니다. 이미 압축을 푼 배포 폴더를 받았다면 3번부터 진행하세요.
2. Windows 탐색기에서 ZIP을 우클릭하고 **모두 압축 풀기**를 선택합니다. 예를 들어 `D:\Apps\VideoDownloaderPortable`처럼 본인 계정에 쓰기 권한이 있는 로컬 폴더에 전체 내용을 풉니다.
3. 아래 구성처럼 실행 파일, `tools`, `extension`이 한 폴더에 있는지 확인하고 **`VideoDownloader.exe`**를 실행합니다. 현재 소스로 빌드한 앱의 창 제목은 **dmVideoDownloader**입니다. 이전 배포본에는 **영상 다운로더**로 표시될 수 있습니다.
4. 앱이 열리면 **설정 → 일반 → 다운로드 저장 위치 → 찾아보기**로 저장 폴더를 선택합니다. 기본 위치는 Windows의 사용자 다운로드 폴더 아래 `Videos`입니다. 저장 폴더는 쓰기 가능한 로컬 경로를 사용하세요.
5. 같은 창에서 **영상 도구 → 도구 확인**을 누릅니다. yt-dlp와 FFmpeg가 모두 **사용 가능**으로 표시되는지 확인하고 **저장**을 누릅니다. yt-dlp는 영상 분석에, FFmpeg는 영상과 음성을 병합하거나 저장 형식을 맞추는 데 사용합니다.

```text
VideoDownloaderPortable/
├─ VideoDownloader.exe        앱 실행
├─ VideoNativeHost.exe        Chrome과 앱 사이의 연결 도구
├─ tools/
│  ├─ yt-dlp.exe
│  └─ ffmpeg.exe
├─ extension/                 Chrome에서 선택할 폴더
│  └─ manifest.json           이 파일과 나머지 확장 파일이 함께 있어야 함
├─ notices/                   동봉 도구의 출처와 라이선스
├─ SHA256SUMS.txt
└─ README.txt
```

- **실행 환경** Windows에 Microsoft Edge WebView2 Runtime이 필요합니다. Runtime이 없다는 안내가 나오면 Microsoft 페이지의 **Evergreen Bootstrapper**로 설치한 뒤 다시 실행하세요. [Microsoft WebView2 다운로드](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download)
- **배포본 구분** ZIP을 푸는 방식이며 앱 설치 마법사나 개발 도구가 필요 없습니다. 기존 로컬 검증용 ZIP은 미서명이고 빌드 시점의 UI를 담고 있습니다. 소스만 있다면 저장소 루트에서 `npm.cmd ci` 후 `npm.cmd run package:portable -- "<검증된 도구 루트>"`를 실행해 `dist/portable-*/VideoDownloaderPortable-win-x64.zip`을 만듭니다. 이 빌드에는 개발 환경과 검증된 도구 입력이 필요합니다. [빌드 환경](BUILD.md) · [도구 입력과 패키징](PACKAGING.md#2-런타임-결과물-구조)
- **ZIP 확인** 배포자가 같은 이름의 `.sha256` 파일을 함께 제공했다면 ZIP이 있는 폴더의 PowerShell에서 `Get-FileHash -Algorithm SHA256 .\VideoDownloaderPortable-win-x64.zip`을 실행합니다. 출력의 `Hash`와 `.sha256` 파일의 첫 값을 비교하세요.

## 2. Chrome 확장 설치와 연결

Chrome 감지 기능을 쓸 때 진행합니다. 확장이 요구하는 최소 Chrome 버전은 120입니다. 앱과 Chrome은 같은 Windows 사용자 계정에서 실행하고, 테스트 중에는 앱을 열어 두세요.

### 확장 폴더 불러오기

1. 앱에서 **설정 → Chrome 확장 프로그램 → 확장 프로그램 설치 안내**를 엽니다.
2. Chrome 관리 화면이 열리지 않으면 **Chrome 확장 관리 주소 복사**를 누르거나 Chrome 주소창에 `chrome://extensions`를 직접 입력합니다.
3. Chrome 확장 관리 화면에서 **개발자 모드**를 켭니다. **압축해제된 확장 프로그램을 로드합니다**를 누른 뒤, 배포본에서 `manifest.json`이 바로 보이는 **`extension` 폴더**를 선택합니다.
4. **dmVideoDownloader 영상 감지** 카드가 생기고 활성화되었는지 확인합니다. Chrome 도구 모음의 퍼즐 모양 **확장 프로그램** 메뉴에서 이 항목을 찾을 수 있습니다. 자주 쓰면 핀으로 고정하세요. [Chrome의 로컬 확장 로드 안내](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked)

### 실제 확장 ID 등록과 왕복 테스트

1. Chrome에서 확장 아이콘을 눌러 팝업을 열고 **앱 연결 → ID 복사**를 누릅니다. 복사할 수 없으면 팝업이나 확장 관리 카드에 표시된 ID를 직접 복사합니다.
2. 앱의 **설정 → Chrome 확장 프로그램 → 확장 ID**에 붙여 넣습니다. 실제 ID는 소문자 `a`~`p`로 이루어진 32자입니다.
3. 앱에서 **호스트 등록**을 누릅니다. 등록이 끝나면 **등록됨 · 연결 테스트 필요**가 표시됩니다. 등록은 현재 Windows 사용자에 대해 즉시 적용됩니다.
4. **앱의 연결 테스트**를 먼저 누릅니다. 앱이 대기 상태가 되면 **30초 안에 Chrome 팝업의 연결 테스트**를 누르고 결과가 나올 때까지 팝업을 열어 둡니다.
5. 양쪽에서 왕복 성공 또는 마지막 성공 시각을 확인합니다. 테스트가 끝나면 임시 연결이 닫히므로 현재 연결 표시가 바뀔 수 있습니다. 실패하면 [문제 해결](#6-문제-해결)을 참고하세요.

## 3. 영상 다운로드

저장할 권한이 있는 공개 영상만 사용하세요. 앱은 공개 HTTP(S)의 MP4·WebM, 종료된 비암호화 HLS 및 지원하는 정적 DASH를 처리합니다. 로그인 전용 영상, DRM 보호 영상, 라이브 스트림은 저장할 수 없습니다.

### 방법 A. 앱에 주소를 직접 입력

1. 메인 화면의 **영상 URL 직접 입력**에 공개 영상 파일 주소를 붙여 넣습니다. 지원하는 공개 영상 페이지 주소도 분석할 수 있습니다.
2. **분석**을 누르고 결과 표에서 해상도, 영상과 음성 트랙, 파일 형식 등을 확인합니다.
3. 표 위의 **다운로드**를 누릅니다. 앱은 설정한 화질 상한과 저장 형식에 맞춰 포맷을 선택합니다.
4. **다운로드** 작업 표에서 **완료**를 확인한 뒤 **탐색기에서 보기**를 눌러 실제 저장 파일을 찾습니다. 영상이 열리는지 재생해 보세요.

처음 동작을 확인하려면 아래 MDN 공개 MP4 주소를 복사해 같은 절차를 따라 할 수 있습니다.

```text
https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4
```

### 방법 B. Chrome에서 감지한 영상 보내기

1. 연결을 마친 앱을 열어 두고, Chrome의 대상 탭에서 공개 영상을 재생합니다.
2. 그 탭에서 확장 팝업을 열어 **현재 탭 영상** 목록을 봅니다. 후보가 없으면 영상을 다시 재생하고 Chrome이 해당 사이트 접근을 허용하는지 확인하세요. 팝업의 **현재 탭 상세 감지**가 활성화되어 있다면 눌러 추가 후보를 찾을 수 있습니다.
3. 원하는 후보 옆의 **다운로드**를 누릅니다. 팝업에 **앱이 영상 후보를 수신했습니다**가 나오면 Windows 앱으로 돌아갑니다.
4. 앱의 **감지된 영상**에서 받은 후보 옆 **분석**을 누릅니다. 분석 전에는 화질이 **미확인**으로 표시됩니다.
5. 분석 결과 위의 **다운로드**를 누릅니다. 완료 행의 **탐색기에서 보기**로 파일을 확인합니다.

## 4. 다운로드 상태와 이어받기

| 화면 표시 또는 버튼 | 의미와 조작 |
|---|---|
| **대기 중** | 동시 다운로드 한도에 빈자리가 생기면 시작합니다. |
| **영상 확인 중**, **다운로드 중**, **파일 처리 중** | 주소와 포맷을 확인한 뒤 전송하고, 필요하면 영상·음성을 합쳐 최종 파일을 만듭니다. |
| **진행률 / 속도** | 크기를 알면 퍼센트를 표시하고, 전체 크기를 모르면 받은 용량을 표시합니다. 전체 크기와 속도를 알 때 예상 남은 시간이 표시됩니다. |
| **일시정지** / **재개** | 전송을 잠시 멈췄다가 같은 작업을 다시 시작합니다. 조건이 맞으면 **이어받는 중**으로 표시합니다. |
| **실패** / **다시 시도** | 실패 사유를 확인하세요. 일시적인 네트워크 문제는 설정에 따라 자동 재시도하며, **다시 시도**가 표시되면 수동으로 요청할 수 있습니다. |
| **취소** | 해당 작업을 중단하고 그 작업의 미완료 파일을 정리합니다. |
| **완료** / **탐색기에서 보기** | 해당 작업이 실제 저장한 파일을 표시합니다. 화면 하단의 **다운로드 폴더 열기**는 현재 설정의 기본 저장 폴더를 엽니다. |

- **앱을 켜 둔 상태** 공개 파일은 서버가 같은 파일과 정확한 바이트 범위를 확인해 줄 때 이어받습니다. 조각형 HLS·DASH는 재생목록과 조각 목록이 같으면 완료한 조각을 재사용합니다. 조건이 달라지면 처음부터 받습니다.
- **앱을 정상 종료한 뒤** 조건을 충족하는 공개 MP4·WebM은 재실행한 앱에 **같은 주소**를 입력하고 **같은 저장 폴더**로 다운로드하면 이어받을 수 있습니다. 작업 목록 자체는 복원되지 않습니다. 조각형 HLS·DASH의 재실행 후 이어받기와 강제 종료 후 복원은 지원 범위 밖입니다.
- **파일 이름 충돌** 저장 폴더에 같은 이름이 있으면 새 파일 이름에 번호를 붙여 기존 파일을 보존합니다.

## 5. 설정 항목

메인 화면 오른쪽 위의 **설정**을 엽니다. **저장**을 누르면 일반 옵션이 적용됩니다. **취소**는 저장 전 편집을 버리고, **기본값 복원**은 값을 바꾼 뒤 **저장**을 눌러야 적용됩니다.

| 항목 | 기본값 | 선택과 적용 시점 |
|---|---|---|
| **다운로드 저장 위치** | Windows 다운로드 폴더 아래 `Videos` | **찾아보기**로 쓰기 가능한 로컬 폴더를 지정합니다. 새 작업에 적용됩니다. |
| **기본 화질** | 최고 화질 | **4K 이하**, **1080p 이하**, **720p 이하**를 선택할 수 있습니다. 상한 이내에서 가장 높은 가용 화질을 사용합니다. |
| **저장 형식** | 자동 | **MP4**, **MKV**를 지정할 수 있습니다. 원본 영상과 음성을 선택한 형식에 담을 수 없는 경우 **자동** 또는 **MKV**로 바꿔 새 작업으로 시도하세요. |
| **파일 이름** | 제목 | **제목**, **제목-ID**, **날짜-제목**을 선택합니다. |
| **동시 다운로드** | 2개 | 1~4개 중 선택합니다. 한도를 낮추면 이미 실행 중인 작업은 계속 진행하고, 새 작업은 자리가 빌 때까지 대기합니다. |
| **전체 다운로드 속도** | 무제한 | **512 KiB/s**, **1·2·5·10 MiB/s** 중 선택합니다. 모든 활성 작업이 한도를 나눠 쓰며 저장 즉시 진행 중인 작업에도 적용됩니다. |
| **실패 재시도** | 3회 | **0·1·3·5회** 중 선택합니다. 일시적인 네트워크 오류 등에 적용됩니다. |
| **브라우저 영상 자동 감지** | 켜짐 | 값을 바꾸고 저장한 뒤 **연결 테스트**를 다시 완료해야 Chrome 확장이 새 값을 읽습니다. |
| **다운로드 완료 알림** | 켜짐 | 새 작업에 적용됩니다. 알림이 안 보이면 Windows 알림 설정을 확인하세요. |

**호스트 등록**, **연결 복구/재등록**, **연결 해제**는 누르면 즉시 실행합니다. 일반 설정의 **취소**로 이미 실행한 연결 변경을 되돌릴 수 없습니다.

## 6. 문제 해결

| 증상 | 확인 순서 |
|---|---|
| **앱이 열리지 않음** | ZIP에서 파일 전체를 풀었는지 확인합니다. WebView2 오류가 보이면 1절의 Microsoft Runtime을 설치합니다. 미서명 검증본을 Windows가 경고하면 배포 출처와 제공된 해시를 확인하세요. |
| **확장 로드 실패 / manifest 누락** | 배포본의 `extension\manifest.json`이 있는지 확인하고 그 `extension` 폴더를 다시 선택합니다. 소스 폴더나 ZIP을 선택하면 로드할 수 없습니다. 조직 정책으로 개발자 모드가 막혀 있으면 관리자에게 문의하세요. 공개 주소 직접 입력은 Chrome 연결 없이 사용할 수 있습니다. |
| **호스트 등록 또는 연결 테스트 버튼이 비활성** | 실제 확장 ID와 `VideoNativeHost.exe`를 확인합니다. ID만 편집한 상태라면 **호스트 등록**을 완료합니다. 다른 폴더의 등록이나 이전 ID가 표시되면 현재 폴더의 앱에서 **연결 복구/재등록**을 누릅니다. |
| **연결 테스트 시간 초과 / 앱 미실행** | 앱과 확장을 같은 Windows 사용자에서 열고 확장이 활성화되어 있는지 확인합니다. 앱 → 팝업 순으로 30초 이내에 다시 시험합니다. 등록 경로와 Chrome의 실제 ID를 다시 비교하세요. |
| **Chrome 후보 없음** | 대상 탭에서 영상을 재생합니다. 사이트 접근, 팝업의 자동 감지 상태, 확장 활성화 여부를 확인하고 필요하면 탭을 새로고침합니다. 사용 가능한 경우 **현재 탭 상세 감지**를 실행합니다. |
| **도구 누락 / 버전 오류** | **설정 → 영상 도구 → 도구 확인**에서 어떤 도구가 문제인지 확인합니다. 앱 옆 `tools`에 배포본의 `yt-dlp.exe`, `ffmpeg.exe`가 있는지 확인합니다. |
| **인증 필요 / 보호 영상 / 주소 만료** | 인증이나 보호가 필요 없는 공개 영상을 사용합니다. 만료된 주소는 원래 공개 페이지에서 다시 재생·감지한 뒤 새 후보를 분석합니다. |
| **화질 상한 / 컨테이너 오류** | 현재 상한 이내 영상이 있는지 분석 표에서 확인합니다. 상한을 조정하거나 형식을 **자동** 또는 **MKV**로 변경해 저장한 뒤 새 작업을 시작합니다. |
| **저장 실패** | 저장 폴더의 쓰기 권한과 빈 공간을 확인합니다. 네트워크 공유 경로 대신 쓰기 가능한 로컬 폴더를 선택하세요. |
| **설정 파일 손상** | 설정 창에 **손상 파일 백업 후 기본값 저장**이 표시되면 그 버튼으로 복구합니다. 원본은 `data/settings.backup-*.json`에 보관됩니다. 지원하지 않는 설정 버전이라면 원본을 보존하고 호환되는 앱을 사용하세요. |

## 7. 이동·업데이트·제거

### 폴더 이동

1. 필요한 작업을 마친 뒤 앱을 종료하고 포터블 폴더 전체를 옮깁니다. `data/settings.json`도 함께 옮깁니다.
2. Chrome에서 옛 확장 항목을 제거하고 새 위치의 `extension` 폴더를 로드합니다. 새 팝업에 표시된 실제 ID를 복사합니다.
3. 새 위치의 앱을 열어 **설정 → Chrome 확장 프로그램**에 ID를 붙여 넣고 **연결 복구/재등록**을 누릅니다. 앱과 팝업에서 연결 테스트를 반복합니다.
4. 다운로드 폴더를 앱 폴더 안에 뒀다면 **다운로드 저장 위치**를 새 경로로 수정하고 저장합니다.

### 업데이트

1. 앱을 종료하고 `data/settings.json`을 백업합니다. 다운로드 폴더를 포터블 폴더 안에 뒀다면 저장 영상도 보존합니다.
2. 새 ZIP의 앱, 호스트, 확장, 도구를 같은 배포본으로 맞춥니다. 새 폴더에 풀었다면 백업한 `data/settings.json`을 같은 상대 경로에 둔 뒤 새 앱을 실행합니다.
3. 같은 경로의 확장을 교체했다면 `chrome://extensions`에서 확장을 새로고침합니다. 경로가 바뀌었다면 새 폴더를 로드합니다. 앱에서 실제 ID와 등록 경로를 확인하고 필요하면 **연결 복구/재등록** 후 연결 테스트를 진행합니다.

### 제거

1. Chrome을 연결해 사용했다면 포터블 폴더를 지우기 전에 해당 위치의 앱을 열고 **설정 → Chrome 확장 프로그램 → 연결 해제**를 누릅니다.
2. Chrome의 `chrome://extensions`에서 **dmVideoDownloader 영상 감지**를 제거합니다.
3. 앱을 종료하고 보관할 영상과 `data/settings.json`을 다른 위치에 복사한 뒤 포터블 폴더를 삭제합니다. 연결 해제 자체는 영상이나 설정 파일을 삭제하지 않습니다.
