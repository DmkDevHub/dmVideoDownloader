영상 다운로더 0.1.0 · Windows 11 x64 포터블

ZIP 전체를 쓰기 가능한 로컬 폴더에 풀고 VideoDownloader.exe를 실행합니다.
Windows에 Microsoft Edge WebView2 Runtime이 필요합니다.
실행 파일, tools 폴더, extension 폴더는 같은 위치에 둡니다.

영상 주소를 입력하거나 Chrome에서 후보를 보낸 뒤 앱에서 분석과 다운로드를 선택합니다.
설정에서 저장 폴더, 화질, 파일 형식 및 미디어 도구 상태를 확인합니다.
실행 후 data/settings.json에 설정이 저장됩니다.

Chrome 연결
1. 앱의 [설정] → [Chrome 확장 프로그램] → [확장 프로그램 설치 안내]를 엽니다.
2. Chrome의 chrome://extensions에서 개발자 모드를 켜고
   [압축해제된 확장 프로그램을 로드합니다]로 이 폴더의 extension을 선택합니다.
   관리 주소가 자동으로 열리지 않으면 앱의 [Chrome 확장 관리 주소 복사]를 사용합니다.
3. Chrome 확장 카드 또는 팝업의 실제 ID를 앱의 [확장 ID]에 입력하고 [호스트 등록]을 누릅니다.
4. 앱에서 [연결 테스트]를 누른 뒤 30초 안에 Chrome 팝업에서도 [연결 테스트]를 누릅니다.
   마지막 왕복 확인 결과를 앱과 팝업에서 확인합니다.

폴더 이동과 연결 해제
- 실행 중인 작업을 마친 뒤 앱을 종료하고 전체 폴더를 이동합니다.
- Chrome에서 이동한 extension 폴더를 다시 로드한 뒤 실제 ID를 확인합니다.
- 새 위치의 앱에서 해당 ID로 [연결 복구/재등록]을 실행하고 연결 테스트를 반복합니다.
- 다운로드 폴더를 앱 폴더 안에 지정했다면 이동 뒤 설정에서 새 저장 위치를 확인합니다.
- 사용을 끝낼 때는 앱 설정에서 [연결 해제]를 실행한 후 Chrome에서 확장을 제거합니다.
  연결 해제 후에도 설정과 다운로드 파일은 보관됩니다.

다운로드와 문제 해결
- MP4·WebM, 종료된 비암호화 HLS, 지원하는 정적 DASH의 공개 주소를 분석할 수 있습니다.
- 자동 감지에 보이지 않는 열린 플레이어는 Chrome 팝업의 [현재 탭 상세 감지]로 확인할 수 있습니다.
- 화질 상한, 저장 위치와 컨테이너는 새 작업에 적용됩니다.
- 앱 실행 중 같은 파일과 바이트 범위가 확인되면 끊긴 공개 파일을 이어받습니다.
  조각형 HLS/DASH나 확인할 수 없는 서버 응답은 처음부터 다시 받습니다.
- 도구 오류는 설정의 미디어 도구 검사에서 확인합니다. 두 실행 파일은 tools 폴더에 있습니다.
- 로그인·보호 안내가 나오면 인증이 필요 없는 공개 영상을 사용합니다.
- 연결 문제는 확장 활성화, 실제 확장 ID, 앱 실행 여부, 호스트 경로 순으로 확인합니다.
- 업데이트 전에 앱을 종료합니다. 기존 data/settings.json을 보존하고 새 앱의 위치에서
  확장 ID와 호스트 등록을 다시 확인합니다.

이 패키지는 서명되지 않은 로컬 검증용 빌드입니다.
도구 출처와 라이선스는 notices 폴더에 있습니다.
